## Portfolio blurb

Shellmason is a Windows desktop app that builds a PowerShell command from cascading menus and a fill-in sentence, then runs it and keeps the output in the same window. A curated tree covers everyday administration, and commands already installed on the machine can be turned into the same form. Elevation goes through a UAC prompt to a separate helper, with console output returned on a named pipe, and passwords stay out of the preview and off the command line. It is a personal project, written on personal time and equipment, and released under the MIT license.
